# 安装算量（anzhuang-suanliang）

从安装工程施工图快速生成**概算清单底稿**和**物资计划草稿**，服务目标是出量、备料、图审查量和专业软件结果交叉核对；不是金额计价工具，也不是结算量工具。

## 0.2.0 优化概览

- 对接 `cad-file-reader >= 0.18.0`，在扫描层记录底座版本和测量候选兼容状态。
- 支持把 CAD 识图产生的长度、面积、体积候选导入“CAD测量候选核对”工作表；这些值只作识图证据，`final_quantity=false`。
- 算量口径、材料量、损耗和核对清单仍由本技能负责，不把识图候选直接当工程量。

## 能做什么

- 输入：安装工程 DWG，或已生成的 `.scan.json` 索引。
- 输出：一个多工作表 xlsx，包含口径说明、规范约束、双口径映射、导管与桥架、电线电缆、干线电缆、设备、匹配情况、配电箱回路、未匹配坐标簇、水专业、水系统分区、连通性核对、立管识别、支架估算、置信度分级、总量守恒、材料表提取、材料归并、立管估算和核对清单。
- 覆盖对象：导管、电线、电缆、桥架、给排水、喷淋、支吊架、设备、消防报警、应急照明。
- 双口径：
  - 概算清单口径：按 GB 50856 的清单项目思路整理分项、单位、项目特征和草稿量。
  - 物资计划口径：按净量、预留、芯数展开和损耗折算订货量。
- 回路规格按就近标注匹配；未匹配、歧义、推测项保留在核对清单中，不硬凑。

## 用法

先扫描 DWG，再汇总出表：

```bash
python scripts/mep_scan.py 平面图.dwg --out 平面.json
python scripts/mep_scan.py 系统图.dwg --out 系统.json
python scripts/mep_scan.py 干线平面图.dwg --out 干线.json

python scripts/mep_plan.py \
  --scan 平面.json \
  --system 系统.json \
  --trunk-scan 干线.json \
  --out-prefix 安装计划
```

如果已有 `.scan.json`，直接把多个平面扫描 JSON 传给 `mep_plan.py --scan`，不需要重新扫描 DWG。

`mep_scan.py` 会自动查找同级或常见安装位置的 `cad-file-reader`（建议 0.18.0+）；若找不到，设置环境变量：

```bash
export CAD_SKILL_DIR=/path/to/cad-file-reader
```

## 依赖

- `cad-file-reader >= 0.18.0`：读取 DWG，并在扫描结果记录版本/测量候选兼容状态；`mep_plan.py --cad-measurement` 可导入测量候选做识图复核，候选不参与算量。
- Python ≥3.10。
- openpyxl：生成 xlsx。
- 常见系统：macOS/Linux；扫描层当前以本机 CAD 解析环境为主。

## 依据

技能只记录规范口径和边界，不复制规范全文。当前约束和映射参考：

- GB 50856-2013：通用安装工程量计算规范，用于概算清单口径。
- GB 50500-2013：建设工程工程量清单计价规范，用于项目特征与计价边界。
- GB 50015-2019：建筑给水排水设计标准，用于给排水系统分档。
- GB 50084-2017：自动喷水灭火系统设计规范，用于喷淋管道与喷头口径。
- GB 50116-2013：火灾自动报警系统设计规范，用于报警点位与配线。
- GB 51309-2018：消防应急照明和疏散指示系统技术标准，用于应急照明。
- GB 51348-2019：民用建筑电气设计标准，用于电气干线与末端分档。
- GB 50974-2014：消防给水及消火栓系统技术规范，用于消防水。
- GB 50261-2017：自动喷水灭火系统施工及验收规范，用于喷淋施工口径。
- GB 50303-2015：建筑电气工程施工质量验收规范，用于电气施工口径。
- GB 55024-2022：建筑电气与智能化通用规范，用于强制性与系统边界提示。
- GB 50166-2019：火灾自动报警系统施工及验收标准，用于报警施工口径。

## 边界

1. 输出是概算底稿和计划草稿；±5%~10% 是常见计划带，不承诺结算精度。
2. 不输出概算金额、综合单价、措施费、规费和税金。
3. 管线以水平投影为主；立管、竖向路由、管件、套管和检修口需人工核对或另给参数。
4. 回路标注覆盖不到的管段进入未匹配表，不硬展开规格。
5. 桥架单段超过 `tray_max_segment_mm`（默认 50m）按异常剔除，剔除量单独列出。
6. 电线展开公式为 `(路由长 + 两端预留) × 芯数`；电缆按 `路由长 + 两端预留` 展开。
7. 支吊架按间距估算，仅供备料，不替代抗震支吊架、成品支吊架和深化设计。
8. 同一设备跨图重复、天正自定义实体、乱码标注、材料表缺失或图例不一致时必须人工核对。
9. 不能替代翻样、下料、专业算量软件、结算审计和合同计量。
